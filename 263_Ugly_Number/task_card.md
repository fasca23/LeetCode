**Подход: Деление на 2, 3, 5**

1. **Идея:** Уродливое число = 2^a × 3^b × 5^c. Делим на 2 пока делится, потом на 3, потом на 5. Если в итоге осталась 1 — все простые множители были 2/3/5.
2. **Логика:** `if n <= 0: return False`. Для каждого делителя [2, 3, 5]: пока `n % d == 0` → `n //= d`. Вернуть `n == 1`.
3. **Время:** O(log n) — каждое деление уменьшает число.
4. **Память:** O(1).

**Ключевой момент:** Отрицательные числа и 0 — не уродливые. Проверка `n <= 0` обязательна.
