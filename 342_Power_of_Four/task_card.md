**Подход: Деление на 4**

1. **Идея:** Степень четвёрки = 4^k. Делим на 4 пока делится без остатка. Если в итоге осталась 1 — все множители были четвёрки.
2. **Логика:** `if n <= 0: return False`. Пока `n % 4 == 0`: `n //= 4`. Вернуть `n == 1`.
3. **Время:** O(log₄ n) — каждое деление уменьшает число вчетверо.
4. **Память:** O(1).

**Ключевой момент:** Отрицательные и 0 — не степени четвёрки. Альтернатива: битовая проверка (n > 0, n & (n-1) == 0, и n % 3 == 1).
