**Подход: Перебор с подсчётом битов**

1. **Идея:** Перебираем все часы (0-11) и минуты (0-59). Считаем количество единичных битов в каждом. Если сумма = turnedOn — форматируем время.
2. **Логика:** Для h от 0 до 11: для m от 0 до 59: если `bin(h).count('1') + bin(m).count('1') == turnedOn` → `f"{h}:{m:02d}"`.
3. **Время:** O(12 × 60) = O(1) — фиксированное количество.
4. **Память:** O(1) — не считая результата.

**Ключевой момент:** Светодиоды = единичные биты. Часы показывают 4 бита для часов, 6 для минут.
