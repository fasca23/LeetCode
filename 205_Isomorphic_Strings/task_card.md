**Подход: Два словаря (прямое и обратное отображение)**

1. **Идея:** Изоморфизм = можно заменить символы s на символы t однозначно в обе стороны. Один словарь: s→t, второй: t→s. Если отображение ломается — False.
2. **Логика:** `map_st = {}`, `map_ts = {}`. Для каждой пары (ch_s, ch_t): если ch_s уже связан с другим ch_t ИЛИ ch_t уже связан с другим ch_s → False. Иначе сохраняем связи.
3. **Время:** O(n) — один проход.
4. **Память:** O(1) — словари ограничены алфавитом (ASCII — 256 символов).

**Ключевой момент:** Нужны оба словаря. `s="ab" t="cc"`: без обратного словаря a→c и b→c пройдёт, но c не может соответствовать и a и b одновременно.
