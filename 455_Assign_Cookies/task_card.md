**Подход: Жадный алгоритм**

1. **Идея:** Сортируем оба массива. Идём по детям и печенью. Если печенье подходит ребёнку — отдаём, идём к следующему. Иначе — берём большее печенье.
2. **Логика:** `g.sort(), s.sort()`. `i = j = 0`. Пока i < len(g) и j < len(s): если `s[j] >= g[i]` → `i += 1`, `j += 1` (ребёнок доволен). Иначе `j += 1`. Вернуть i.
3. **Время:** O(n log n + m log m) — сортировка.
4. **Память:** O(1).

**Ключевой момент:** Самый маленький ребёнок получает самое маленькое подходящее печенье. Это оптимально — не тратим большое печенье на маленькое желание.
