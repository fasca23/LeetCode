**Подход: Бинарный поиск по высоте**

1. **Идея:** Полное дерево: все уровни заполнены кроме, возможно, последнего. Сравниваем высоту левого и правого поддеревьев. Если равны — левое полно (2^h узлов). Если нет — правое полно на уровень меньше.
2. **Логика:** Для узла считаем высоту левого (идём влево до конца) и правого (идём вправо). Если равны → левое полно: `(1 << left_h) + countNodes(root.right)`. Иначе → правое полно: `(1 << right_h) + countNodes(root.left)`.
3. **Время:** O(log² n) — на каждом уровне считаем высоту за O(log n), уровней O(log n).
4. **Память:** O(log n) — стек рекурсии.

**Ключевой момент:** Сравнение высот левого и правого краёв говорит какая часть дерева полная. Полное поддерево считаем формулой без обхода.
