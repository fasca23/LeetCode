**Подход: Два словаря (буква→слово и слово→буква)**

1. **Идея:** Как изоморфные строки, но для слов. Два словаря: pattern→word и word→pattern. Если какое-то отображение ломается — False.
2. **Логика:** Разбить s на слова. Если длина не совпадает с pattern → False. Для каждой пары (буква, слово): если буква уже связана с другим словом ИЛИ слово уже связано с другой буквой → False. Иначе сохранить.
3. **Время:** O(n) — один проход.
4. **Память:** O(n) — два словаря.

**Ключевой момент:** Нужны оба направления. `pattern="abba", s="dog dog dog dog"` без обратного словаря пройдёт, но dog не может соответствовать и a и b.
