**Подход: Счётчик частот + повторный проход**

1. **Идея:** Первый проход: считаем частоты всех символов. Второй проход: ищем первый символ с частотой 1.
2. **Логика:** `count = Counter(s)`. Для i, ch в enumerate(s): если `count[ch] == 1` → вернуть i. После цикла → -1.
3. **Время:** O(n) — два прохода.
4. **Память:** O(1) — алфавит ограничен (26 букв).

**Ключевой момент:** Нужно два прохода: сначала посчитать все частоты, потом найти первый уникальный. Один проход не сработает — решение о уникальности зависит от всей строки.
