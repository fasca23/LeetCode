**Подход: Счётчик частот**

1. **Идея:** Палиндром: все буквы парами + максимум одна нечётная в центре. Считаем частоты. Для каждой: чётное количество — берём все, нечётное — берём (частоту - 1). Если были нечётные — добавляем 1 в центр.
2. **Логика:** `count = Counter(s)`. `length = 0`, `has_odd = False`. Для freq в count.values(): `length += freq // 2 * 2`. Если `freq % 2 == 1` → `has_odd = True`. Вернуть `length + (1 if has_odd else 0)`.
3. **Время:** O(n) — один проход.
4. **Память:** O(1) — алфавит ограничен.

**Ключевой момент:** Нечётные количества используются как чётные (минус 1), и одна из нечётных может занять центр.
