**Подход: Сборка с конца**

1. **Идея:** Убираем дефисы, верхний регистр. Идём с конца, набираем группы по k символов, вставляем дефис между группами.
2. **Логика:** `s = s.replace('-', '').upper()`. Идём с конца: собираем группы по k, между ними дефис. Первая группа (в начале) может быть короче k.
3. **Время:** O(n) — один проход.
4. **Память:** O(n) — строка результата.

**Ключевой момент:** Идём с конца потому что первая группа может быть короче, а все остальные — ровно по k. С конца это удобнее.
