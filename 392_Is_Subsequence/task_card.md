**Подход: Два указателя**

1. **Идея:** Идём по t. Указатель на s двигается только когда символы совпали. Если прошли всю s — подпоследовательность.
2. **Логика:** `i = 0` (указатель на s). Для ch в t: если `i < len(s)` и `s[i] == ch` → `i += 1`. Вернуть `i == len(s)`.
3. **Время:** O(n) — один проход по t.
4. **Память:** O(1) — указатель.

**Ключевой момент:** Подпоследовательность — символы идут в том же порядке, но не обязательно подряд. "abc" — подпоследовательность "aXbYc".
