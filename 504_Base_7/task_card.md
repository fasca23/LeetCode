**Подход: Деление на 7 с остатком**

1. **Идея:** Классический перевод в систему счисления. Делим на 7, остатки — цифры (0-6). Собираем в обратном порядке.
2. **Логика:** `if num == 0: return "0"`. `sign = "-" if num < 0 else ""`. `num = abs(num)`. Пока num > 0: `result = str(num % 7) + result`, `num //= 7`. Вернуть sign + result.
3. **Время:** O(log₇ n) — число цифр.
4. **Память:** O(1) — строка результата.

**Ключевой момент:** Знак обрабатываем отдельно. 0 — особый случай (иначе цикл не выполнится ни разу).
