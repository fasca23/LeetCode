**Подход: Жадный с таблицей номиналов**

1. **Идея:** Сортируем номиналы по убыванию (включая составные: M, CM, D, CD, C, XC, L, XL, X, IX, V, IV, I). Для каждого вычитаем сколько можем, добавляя соответствующий символ.
2. **Логика:** Таблица `[(1000,"M"), (900,"CM"), ... (1,"I")]`. Для каждой пары `(value, symbol)`: пока `num >= value`: `num -= value`, `result += symbol`.
3. **Время:** O(1) — максимум 15 итераций (13 номиналов × вычитания).
4. **Память:** O(1) — строка результата.

**Ключевой момент:** Составные номиналы (CM=900, CD=400) позволяют избежать повторений больше 3 раз (IIII → IV).
