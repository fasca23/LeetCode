**Подход: Математическое решение**

1. **Идея:** Если n кратно 4 — первый игрок проигрывает. Иначе выигрывает. Причина: при n % 4 != 0 первый может взять столько, чтобы оставить кратное 4, и далее поддерживать это.
2. **Логика:** `return n % 4 != 0`. Если остаток 0 — проигрыш, иначе выигрыш.
3. **Время:** O(1) — одна операция.
4. **Память:** O(1).

**Ключевой момент:** Кратность 4 — ключевая позиция. Из n % 4 == 0 любой ход оставляет некратное 4, а противник может вернуть кратное 4.
