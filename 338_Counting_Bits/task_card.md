**Подход: Динамическое программирование**

1. **Идея:** Число i = (i // 2) с добавленным младшим битом. Количество единиц в i = количество единиц в i//2 + последний бит (0 или 1).
2. **Логика:** `ans[0] = 0`. Для i от 1 до n: `ans[i] = ans[i >> 1] + (i & 1)`. `i >> 1` — это i//2, `i & 1` — младший бит.
3. **Время:** O(n) — один проход.
4. **Память:** O(n) — массив результата.

**Ключевой момент:** Используем ранее посчитанные значения для меньших чисел. Без DP пришлось бы для каждого числа считать биты за O(log n).
