**Подход: Счётчик частот символов**

1. **Идея:** Анаграмма = одинаковые символы с одинаковой частотой. Считаем частоты в s, вычитаем для t. Если все нули — анаграмма.
2. **Логика:** `count = {}`. Для ch в s: `count[ch] += 1`. Для ch в t: `count[ch] -= 1`. Если какое-то значение не 0 → не анаграмма.
3. **Время:** O(n) — один проход по обеим строкам.
4. **Память:** O(1) — словарь ограничен алфавитом (26 букв).

**Ключевой момент:** Сортировка обеих строк O(n log n) тоже работает, но медленнее. Счётчик — O(n).
