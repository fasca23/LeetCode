**Подход: Сортировка + два указателя**

1. **Идея:** Сортируем массив. Фиксируем первое число (i). Для оставшейся части двумя указателями ищем пару с суммой = -nums[i]. Пропускаем дубликаты на всех трёх позициях.
2. **Логика:** `nums.sort()`. Для i от 0 до n-3: если i > 0 и nums[i] == nums[i-1] → continue. `left=i+1, right=n-1`. Пока left < right: сумма трёх = 0 → сохраняем, двигаем оба и пропускаем дубликаты. Сумма < 0 → left++. Сумма > 0 → right--.
3. **Время:** O(n²) — внешний цикл O(n), внутренний O(n).
4. **Память:** O(1) — не считая результата.

**Ключевой момент:** Сортировка позволяет использовать два указателя и пропускать дубликаты. Без сортировки — O(n³).
