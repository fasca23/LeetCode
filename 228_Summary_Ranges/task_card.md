**Подход: Один проход с отслеживанием начала диапазона**

1. **Идея:** Идём по массиву. Запоминаем начало диапазона. Пока числа идут подряд — двигаемся. Как разрыв — записываем диапазон (start→end или просто start) и начинаем новый.
2. **Логика:** `start = nums[0]`. Для i от 1 до n: если `nums[i] != nums[i-1] + 1` → закрываем диапазон, `start = nums[i]`. В конце закрываем последний.
3. **Время:** O(n) — один проход.
4. **Память:** O(1) — не считая результата.

**Ключевой момент:** Диапазон из одного числа = "7". Из нескольких = "7→9".
