**Подход: Побитовая обработка**

1. **Идея:** Каждые 4 бита = одна шестнадцатеричная цифра. Берём младшие 4 бита (`num & 15`), превращаем в символ. Сдвигаем на 4 вправо (`num >> 4`). Повторяем.
2. **Логика:** `if num == 0: return "0"`. `hex_chars = "0123456789abcdef"`. Пока num != 0 и длина < 8: `result = hex_chars[num & 15] + result`, `num >>= 4`.
3. **Время:** O(1) — максимум 8 итераций (32 бита / 4).
4. **Память:** O(1) — строка результата.

**Ключевой момент:** Для отрицательных чисел Python использует бесконечную точность. Ограничение 8 цифр и обработка через битовые операции дают правильный дополнительный код.
