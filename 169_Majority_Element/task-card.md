**Подход: Алгоритм Бойера-Мура (голосование)**

1. **Идея:** Мажоритарный элемент (> n/2) переживёт попарное исключение. Идём по массиву: если счётчик 0 → новый кандидат. Текущий равен кандидату → +1, иначе −1.
2. **Логика:** `candidate = None, count = 0`. Для каждого num: если `count == 0` → `candidate = num`. `count += 1 if num == candidate else -1`.
3. **Время:** O(n) — один проход.
4. **Память:** O(1) — две переменные.

**Ключевой момент:** Алгоритм гарантирует что кандидат — мажоритарный элемент, только если такой существует (что дано по условию).
