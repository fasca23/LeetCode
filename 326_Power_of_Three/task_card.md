**Подход: Деление на 3**

1. **Идея:** Степень тройки = 3^k. Делим на 3 пока делится без остатка. Если в итоге осталась 1 — все множители были тройки.
2. **Логика:** `if n <= 0: return False`. Пока `n % 3 == 0`: `n //= 3`. Вернуть `n == 1`.
3. **Время:** O(log₃ n) — каждое деление уменьшает число втрое.
4. **Память:** O(1).

**Ключевой момент:** Отрицательные и 0 — не степени тройки. Проверка `n <= 0` обязательна.
