**Подход: Два указателя**

1. **Идея:** Медленный указатель (pos) — куда ставить ненулевой элемент. Быстрый (i) — ищет ненулевые. Нашли ненулевой — ставим на pos, pos++. После цикла заполняем хвост нулями.
2. **Логика:** `pos = 0`. Для i от 0 до n: если `nums[i] != 0` → `nums[pos] = nums[i]`, `pos += 1`. После цикла: для j от pos до n → `nums[j] = 0`.
3. **Время:** O(n) — один проход.
4. **Память:** O(1) — на месте.

**Ключевой момент:** Порядок ненулевых сохраняется потому что быстрый указатель идёт последовательно, а медленный — на первое свободное место.
