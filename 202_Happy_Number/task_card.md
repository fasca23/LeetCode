**Подход: Алгоритм Флойда (быстрый/медленный) или set**

1. **Идея:** Процесс либо приходит к 1, либо зацикливается. Можно хранить все встреченные числа в set — если повторилось, то не счастливое. Либо использовать два указателя как в задаче о цикле.
2. **Логика (set):** `seen = set()`. Пока `n != 1` и `n not in seen`: `seen.add(n)`, `n = sum(int(d)**2 for d in str(n))`. Вернуть `n == 1`.
3. **Время:** O(log n) итераций — каждая итерация уменьшает число.
4. **Память:** O(log n) для set.

**Ключевой момент:** Сумма квадратов цифр уменьшается быстро: 999 → 243, 9999 → 324. Цикл гарантированно либо сойдётся к 1, либо войдёт в цикл (4→16→37→58→89→145→42→20→4).
