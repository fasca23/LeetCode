**Подход: Математическая формула (числовой корень)**

1. **Идея:** Числовой корень = n % 9, кроме случаев: n == 0 → 0, n % 9 == 0 и n > 0 → 9. Это следует из свойств делимости на 9.
2. **Логика:** `if n == 0: return 0`. `if n % 9 == 0: return 9`. `return n % 9`.
3. **Время:** O(1) — одна операция.
4. **Память:** O(1).

**Ключевой момент:** Число и сумма его цифр дают одинаковый остаток при делении на 9. Поэтому результат — это остаток от деления n на 9 (с поправкой на 0).
